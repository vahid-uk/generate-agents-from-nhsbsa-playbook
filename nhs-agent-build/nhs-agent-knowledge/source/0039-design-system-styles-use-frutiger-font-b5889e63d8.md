# Styles – Use the NHS Frutiger font

Frutiger is the brand font for the NHS. NHS England has a licence for 3 weights of the font which NHS organisations in England can sign up to use.

## Register for a free licence

One person in each NHS organisation in England can sign up for a licence so their organisation can use the font. You can register if you:

- are the main person responsible for managing font use in your organisation (for example, in the communications or IT team)

- have the authority to register on behalf of your organisation

Once you have registered, you can download the font files and host them locally. Or you can apply the font to your website or online service by linking to our hosted files. There is no limit to the number of people in your organisation who can use the files.

If you do not register here for a licence, you must buy your own licence.

If your organisation already has a licence for desktop applications (such as graphic design software) and for enough users, you do not need to do anything and can continue to use the font in desktop applications.

If you're paying an annual subscription to use the font or require more users, you will save money by registering for a licence for the 3 font weights, as the NHS-wide licence is free and does not expire.

NHS England teams do not need to register to use the font. Find out more on the staff User Centred Design (UCD) SharePoint.

## Frutiger weights included

The licence covers 3 weights. These are:

- Frutiger 65 Bold

- Frutiger 55 Roman

- Frutiger 45 Light, but you cannot use this weight in apps under the licence

You can use the font in these weights online and offline, for example, on your website or in printed products.

If you want to use another weight of Frutiger, for example Frutiger Italic, you must buy your own licence. We do not recommend italic fonts. Some people find them hard to read.

You must also buy your own licence if you want to use Frutiger 45 Light in an app.

## Before you start

To register for a licence to use the font, you must:

- be the most appropriate person to register on behalf of your organisation and have the authority to do this

- have the Organisation Data Service (ODS) code for your NHS organisation – if you do not know it, we will explain how to find it later
