# Help users to – Find British Sign Language content

The British Sign Language (BSL) icon helps BSL users recognise that information is available in BSL.

You can use it:

- to signpost to BSL content or services

- next to content about a BSL service

- in video thumbnails

Do not use the icon on its own without content to explain what it is.

Do not use "BSL" in written content without spelling out the abbreviation. For example, in a video description, explain "Includes British Sign Language (BSL) translation".

## Feed back your findings

We have tested the icon with BSL users but we need more information about:

- how non-BSL users react to the icon as part of their user journey

- where BSL users expect to find the BSL icon as part of their user journey

- if the BSL icon is appropriate for signposting to both BSL translation and interpretation services (like BSL video relay services)
