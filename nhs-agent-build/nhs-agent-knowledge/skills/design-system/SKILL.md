# NHS design system  

## Purpose  
Ensure consistent, accessible, and user-centered design across NHS services, digital tools, and printed materials by adhering to the NHS Frutiger font licensing and usage guidelines.  

## When this skill applies  
- Designing NHS digital services, websites, or applications.  
- Producing printed materials (e.g., leaflets, posters) for NHS organizations.  
- Implementing typography in NHS communications or branding.  

## When this skill does not apply  
- Non-NHS contexts (e.g., private healthcare, non-clinical services).  
- Situations where alternative fonts are legally required or where the NHS Frutiger font is unavailable.  

## NHS requirements  
- Use the NHS Frutiger font with approved weights (Frutiger 65 Bold, Frutiger 55 Roman).  
- Comply with licensing terms for font usage.  
- Ensure accessibility and readability in all implementations.  

## Mandatory requirements  
1. **Font licensing**  
   - Register for a free NHS-wide licence (for organisations in England).  
   - Use only the 3 approved weights (Frutiger 65 Bold, Frutiger 55 Roman, Frutiger 45 Light for non-applications).  

2. **Font usage**  
   - Apply Frutiger 65 Bold for headings and titles.  
   - Use Frutiger 55 Roman for body text.  
   - Avoid italic fonts unless a separate licence is obtained.  

3. **Accessibility**  
   - Ensure sufficient contrast between text and background.  
   - Avoid using Frutiger 45 Light in digital applications.  

## Recommended practices  
- Use the NHS-hosted font files for digital services to avoid licensing issues.  
- Collaborate with communications or IT teams to ensure compliance.  
- Document font usage in design systems or style guides.  

## Do  
- Use Frutiger 65 Bold for headings.  
- Apply Frutiger 55 Roman for body text.  
- Register for a licence if your organisation requires the font.  

## Don't  
- Use italic fonts without a separate licence.  
- Use Frutiger 45 Light in digital applications.  
- Distribute unapproved font weights to external parties.  

## Detailed implementation guidance  
1. **Registration**  
   - Ensure the organisation has an ODS code.  
   - Complete the NHS licence registration form.  

2. **Font deployment**  
   - Download font files for local use or link to NHS-hosted files.  
   - Apply font weights to digital services via CSS or design tools.  

3. **Accessibility checks**  
   - Test text readability on screens and in print.  
   - Verify contrast ratios meet WCAG standards (minimum 4.5:1 for normal text).  

## Decision rules  
- Use Frutiger 65 Bold for emphasis (e.g., headings, buttons).  
- Use Frutiger 55 Roman for body text and labels.  
- Avoid Frutiger 45 Light in digital contexts.  

## Accessibility  
- Ensure text is legible for users with visual impairments.  
- Avoid overuse of bold or italic styles that may reduce readability.  
- Provide alternative text for non-text content (e.g., icons).  

## Security and data considerations  
- Store font files securely to prevent unauthorised distribution.  
- Comply with NHS data protection policies when handling font licences.  

## Testing and quality gates  
- Validate font usage against NHS design system guidelines.  
- Conduct user testing to ensure readability and accessibility.  
- Review compliance with licensing terms during audits.  

## Common failure modes  
- Using unapproved font weights (e.g., italic, Frutiger 45 Light in apps).  
- Failing to register for a licence when required.  
- Ignoring accessibility standards (e.g., poor contrast, illegible text).  

## Exceptions and deviations  
- Use alternative fonts only if explicitly required by legal or regulatory standards.  
- Deviate from font weights if technical constraints prevent compliance (document justification).
